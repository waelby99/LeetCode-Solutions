## Longest Common Prefix

### Complexity Analysis

* **Time Complexity:** `O(n*m)`
    n = number of strings
    m = length of the shortest string
    outter loop loops through number of strings, and the inner loop loops through the shortest string.
* **Space Complexity:** `O(m)`
  we create a substring with m characters
